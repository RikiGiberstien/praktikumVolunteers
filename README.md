# Volunteer Management System

## Overview

A web-based application designed to support volunteer management and coordinate volunteer activities in community centers.

The system provides a central platform for managing volunteer shifts, monitoring their status, and supporting communication between volunteers and administrators.

## Key Features

- **Volunteer Shift Management:** Create and manage volunteer shifts.
- **Shift Status Tracking:** Track pending, confirmed, and cancelled shifts.
- **Domain Management:** Organize volunteer activities by areas and subdomains.
- **Administrator Workflow:** Support shift review, confirmation, and cancellation requests.
- **Email Notifications:** Support email communication related to shift updates and new information.
- **Dashboard:** Present shift information and activity summaries in an organized interface.
- **Notes and Updates:** Maintain relevant information associated with volunteer shifts.
- **AI Integration:** Incorporate AI-powered capabilities to support smarter management and process automation.

## Technologies

- **Frontend:** React
- **Backend:** Node.js
- **Database:** PostgreSQL

## Project Goal

The goal of this project is to simplify volunteer coordination, improve visibility into volunteer activities, and help administrators manage shifts and related workflows efficiently.

The application is developed as a full-stack project, with a frontend interface, backend services, and database integration.
